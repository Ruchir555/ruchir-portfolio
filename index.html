QUANTUM SIMULATION

Qubit dephasing & dynamical decoupling

A single-qubit Bloch-vector simulator comparing free evolution, Hahn echo, and CPMG sequences, with rate sweeps and CSV benchmarks. Ideal pulses refocus deterministic phase accumulation; exponential transverse decay remains in this model.

Python · NumPyExplore project ↗
QUANTUM INFORMATION

Majorization & T-transformations

Research notebooks exploring majorization, pairwise mixing, and entanglement conversion between bosonic modes and qubits. The parameter-finding routine returns mixing strengths and index choices; further notebook sections explore Schmidt distributions, entropy, and conversion protocols.

Python · JupyterExplore project ↗
COLLABORATIVE SCIENTIFIC SOFTWARE

Traxis: particle-track analysis

A collaborative capstone extending the Traxis toolkit for analysing digitised bubble-chamber tracks. The Python/Qt application combines track marking, least-squares circle fitting, momentum and optical-density analysis, and JSON session saving and loading.

Built on the original toolkit by Syed Haider Abidi, Nooruddin Ahmed, and Christopher Dydula; capstone collaborators include Anas Ali and Ruchir Tullu.

Python · SciPy · PyQtExplore project ↗
NUMERICAL METHODS

Computational physics explorations

A collection of numerical-physics learning projects. The Gaussian-integration script compares a sampled sum with SciPy quadrature and the analytical full-line integral, revealing how the estimate converges as sampling increases. Other scripts explore damped oscillators and nanobeam parameters.
