# Ruchir Tullu — Portfolio

A static portfolio for quantum research and scientific computing.

## Files

- `index.html`: biography, research, skills, education, and contact information.
- `style.css`: responsive layout and appearance.
- `.nojekyll`: serves files directly when using GitHub Pages.

## Editing

Edit the HTML for content and CSS for styling. No package installation or build step is needed. Open `index.html` in a browser to preview.

To add the finished thesis, place the approved PDF in an `assets/` folder and link to it from the HTML. Add coding projects with descriptions and links to their repositories or demos.

## Hosting and visibility

Uploading source does not publish a website. Enable hosting separately when ready. Repository visibility and website visibility are separate settings; do not assume that a private repository makes a hosted website private.
